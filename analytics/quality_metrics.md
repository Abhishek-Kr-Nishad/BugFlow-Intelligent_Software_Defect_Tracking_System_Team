# BugFlow – Software Quality Metrics

## 1. Introduction
Software quality metrics help monitor the quality of the BugFlow application by analysing reported defects and their resolution status.

## 2. Key Software Quality Metrics

### 2.1 Total Defects
Counts the total number of defects reported in the system.

### 2.2 Open Defects
Counts the number of defects that are still unresolved.

### 2.3 Resolved Defects
Counts the number of defects that have been fixed.

### 2.4 Defect Resolution Rate
Measures the percentage of reported defects that have been resolved.

Formula:
Resolution Rate = (Resolved Defects / Total Defects) × 100

### 2.5 Severity-wise Defect Distribution
Classifies defects according to their severity, such as High, Medium and Low.

## 3. Additional Metrics for Future Enhancement

- Average defect resolution time.
- Defect trends over time.
- Defect density.
- Release quality metrics.

## 4. Purpose
These metrics help the team understand defect status, monitor software quality and support better project decisions.
